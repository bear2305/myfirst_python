# Early Python Projects (SHS-2)

Welcome! This repository contains my very first Python scripts, built during my second year of Senior High School (SHS-2). These projects mark the beginning of my programming journey, combining fundamental programming logic with concepts learned in school.

## Project Highlight: LC Circuit Calculator

My favorite project in this collection is the **LC Circuit Calculator**. Inspired by our Physics lessons on **Alternating Current (AC) Circuits**, this tool calculates resonant frequency, inductance, or capacitance based on user input.

It uses the theoretical formula for resonant frequency:


$$f = \frac{1}{2\pi \sqrt{LC}}$$

*(Implemented using the rational approximation $\pi \approx \frac{22}{7}$)*

---

## Included Scripts

* **`LC CIRCUIT CALC.py`**

* **Description:** A CLI-based calculator for AC circuit parameters (Frequency $F$, Inductance $L$, Capacitance $C$).


* **Features:** Flexible menu options, input validation, and division-by-zero error handling.




* **`bizz buss game.py`**

* **Description:** A simple interactive implementation of the classic FizzBuzz programming game.


* **Features:** Continuous execution loop that outputs "fizz", "buzz", or "fizzbuzz" based on divisibility by 3 and 5.




* **`triangle area calculator.py`**

* **Description:** A practical geometry utility that calculates the area of a triangle ($A = \frac{1}{2} \cdot \text{base} \cdot \text{height}$).


* **Features:** Robust error handling for invalid strings, non-positive dimensions, and an interactive prompt to repeat calculations.
